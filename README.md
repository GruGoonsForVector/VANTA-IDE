# VANTA-IDE
The official repository and download page of VANTE IDE / Code Editor / Notepad / Simulator an unofficial competitor for VSCode and VIM/NEOVIM

The files to VANTA are all free to download but donating to my Patreon would greatly help funding this project at: https://patreon.com/GruGoonsForVector/project/VANTA all donations big or small are greatly appreciated 😁

To use VANTA go to the branch where the fully assembled .Zip file is assembled ready to be extracted and ready to run no installation or sign-in you can sign-in to save documents across accounts and devices but is not required for usage

# REQUIREMENTS

Python 2.16 above

Windows OS (7-11)

# Controls

VIM/NEOVIM mode and all other commands/keybinds are all available in the in-app settings with built in presets and a built in import tool with simulation mode usable along with code suggestions

Default keyboard layout is QWERTY and UK English (New layouts in later updates) designed to run on 95% or Windows versions (Linux/Mac not supported yet)
